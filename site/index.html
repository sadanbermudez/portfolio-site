Selected work

  • A 20x stall in llama.cpp's Vulkan backend

    0.61 → 0.03 s

    Every reply from my local assistant paused for over a second. Eight measurements traced it to CPU reads of uncached GPU memory; a one-condition fix made snapshots 20 times faster with identical output.

  • An AI agent that runs a physics experiment

    n = 2.004 ± 0.03

    An MCP server gives a local model an optics bench with safety limits it cannot override. Asked a question with a hidden answer, the agent measured it correctly in both runs, and misexplained the physics both times.

  • Odysseus-Jarvis, a private assistant on one laptop

    no cloud inference

    Voice, an agent and a chat hub on one local model server, with memory, tracing, evals and a Docker sandbox for agent code.

The system

AMD Radeon 8060S · 64 GB

One laptop, one model server, every path measured

Jarvis runs on a single AMD laptop: a 35B mixture-of-experts model served by llama.cpp on Vulkan, shared by a voice loop, an agent and a self-hosted chat hub. Claude Code handles typed work. Because everything shares one server, one engine fix sped up every local path.
