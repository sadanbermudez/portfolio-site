Two different questions
New AI approaches attack two separate costs. Some change how the answer is written, so it takes fewer trips through the model. Others change where the model lives, so a model too big for memory runs anyway. The race below is the first; the memory slider is the second.
Word by word
Today's chat models. One trip through the model per piece of text, each waiting for the last. Reliable, and the slowest when the answer is long.
All at once
Diffusion models fill the whole answer over a number of rounds; next-concept models (NCM) sketch a compact plan of the answer and refine it level by level. Fewer trips, but each idea has a catch, which the race shows.
Bigger than memory
The colibri idea: a mixture-of-experts model uses only a few of its parts per word, so the rest can stay on the drive. I ran a 284-billion-parameter model that way on this laptop, then built my own small engine to measure why it is slow.

What the NCM lane is not

I expected the coarse levels to be a blurred version of the board that sharpens. They are not. I decoded this board from the model's codes after each level: the cells right, out of 81, go 0, 0, 1, 2, 1, 2, 0, 4, 6, 5, 5, and then 81 after the last level. A random guess gets about 9. On eight test boards the pattern was the same: the early levels are a plan in the model's own code, and the board only exists once the plan is complete. That is the "concept" in next-concept modelling.

2 · Where the model lives

OLMoE-1B-7B · 1,024 experts · 13 GB

A big model in small memory: the colibri idea

A mixture-of-experts model has many small parts, the experts, and each word uses only 8 of the 64 in every layer. So the experts can live on the drive, with the most used kept in memory. Drag the memory and watch a word go through the 16 layers.

Which experts light up is a simulation with a realistic spread of popular and rare experts. The speed and the streaming text are the measured result for that memory size, from my engine on this laptop.

The same idea at full scale is colibri running a 284-billion-parameter model on this 64 GB laptop, at about half a word per second. To see where that time goes I built my own small engine and measured it: with no memory for experts it writes 1.0 words per second, guessing the next layer's experts early (prefetch) makes that 58% faster, and 8 GB of the 13 GB gets 57% of full speed. The answer was the same text in all 27 conditions.
