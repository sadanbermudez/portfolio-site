In plain words
Argus is my own AI assistant system. Jarvis, the assistant, runs on a language model on my laptop, keeps notes in a memory he can search, can hand hard jobs to Claude, and talks by voice. It is built on Odysseus, an open-source hub, and the hub below is a recreation with sample conversations.
Why it matters
A private assistant keeps your notes on your own machine and answers routine questions in seconds. Building one well takes the everyday work of AI teams: connect a model to tools and memory, send each job to the right model, and test it.
What I built
My layer on top of Odysseus: a memory server over MCP (7 tools, 29 tests), bridges to Claude Code and to free cloud models, a bridge for Windows-only tools, the voice line's local brain, routing, a 13-task evaluation, traces, a supervisor that restarts crashed services, and the llama.cpp engine fix.
What I measured
13 of 13 evaluation tasks passed on the local model with thinking off (median 2.6 s), against 10 of 13 with thinking on (median 19.8 s), so thinking stays off. Mid-conversation, the voice starts speaking in 0.7 s.
Glossary: the technical words on this page
Agent
A language model that works in a loop: it calls a tool, reads the result and decides the next step.
Local model
A language model running on my own laptop rather than in the cloud: here Qwen3.6-35B-A3B on the laptop's GPU.
MCP
Model Context Protocol, an open standard for connecting AI models to tools. A server lists its tools; the model calls them.
Evaluation (eval)
A fixed set of tasks with automatic checks, run again after a change to see whether the system still works.
Persona
The identity and rules a model is given. Jarvis is an Odysseus persona.
Routing
Choosing which model gets each job: local for routine work, Claude for hard multi-step jobs, free cloud models as a fallback.
Thinking mode
A setting where the model reasons at length before answering. Slower, and here it used up the answer budget twice.
Trace
A record of each step of a request, with its timing, for finding what is slow or broken.
Wake word
The word, "Jarvis", that tells the voice line to start listening.

        Ownership

        What is mine, what is Odysseus

        Argus · mine

        • Jarvis in the hub persona, skills and an import builder
        • jarvis-memory vault memory over MCP, 7 tools, 29 tests
        • claude-bridge hard jobs to Claude Code on a subscription, read-only by default, never a shell
        • free-bridge free cloud models as a fallback, text only
        • Tool bridge brings Windows-only MCP tools into the hub
        • Voice the local brain and wake word for the voice line; Daniel's voice inside Odysseus
        • Routing local model for routine work, Claude for hard multi-step jobs, free cloud as fallback
        • Measurement 13-task evaluations, traces, a performance dashboard, a system audit
        • Supervisor a tray app that runs every service and restarts crashed ones
        • Engine fix llama.cpp Vulkan snapshot read, 0.61 s to 0.03 s

        Odysseus · open source

        • The hub a self-hosted app for chat, agents, deep research, documents, email, calendar, notes and tasks
        • Agent loop native tool calling, plan mode and a tool-approval gate
        • MCP client connects to the servers Argus provides
        • Personas and skills where Jarvis's identity and jobs live
        • Model endpoints local engines and API providers, swapped at runtime
        • Cookbook downloads and serves local models
