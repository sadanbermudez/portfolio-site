2026 · personal Running daily

Odysseus-Jarvis: a local-first AI agent hub

A personal AI assistant that runs on a local LLM inside a self-hosted AI hub, with Claude Code as a second brain for hard tasks.

  • Runs Qwen3.6-35B-A3B with llama.cpp on an AMD Radeon GPU, served through an agent framework (Hermes Agent).
  • An MCP memory server over an Obsidian knowledge base: BM25 search, guarded writes, daily logs, 29 automated tests.
  • A delegation bridge that hands hard jobs to Claude Code with least-privilege tool modes.
  • A voice pipeline (Whisper in, Kokoro out, streaming replies) and an OpenAI-compatible speech service.
  • An eval harness of 13 real tasks with deterministic scoring. It picked the settings: thinking off scored 13/13 at about 2.5 s against 10/13 at about 20 s.
  • A tray supervisor that starts and watches eight services, and a system audit that checks health and configuration drift.
